# Changelog

## [1.0.0] - 2026-11-17

### Added
- Fluent SEO metadata manager with configurable defaults.
- Title, description, canonical URL, robots, image, Open Graph, and Twitter metadata.
- JSON-LD structured data rendering.
- Blade `@seo` directive.
- Scoped manager registration for request lifecycle isolation.
- HTML escaping and safe JSON encoding.
- PHPUnit feature tests and GitHub Actions workflow.
